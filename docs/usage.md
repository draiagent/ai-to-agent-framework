# 使用指南

1. 選一項範圍清楚、可檢查成品的工作，例如整理一支短影片。
2. 用 VAD 畫出輸入、處理與交付關係；用 VAC 補足精確規格。
3. 列出實際可用的模型／平台、工具、權限。沒有的能力標明缺口，由人完成或另行配置。
4. 選用與任務相符的 Skill。先跑通單一路徑，不要求全部平台參與。
5. 執行後打開成品，依驗收條件逐項檢查。失敗時回到對應步驟修正。
6. 保留有用做法與例外，經整理後更新 Skill，避免把一次偶然成功當成普遍規則。

## 可直接使用的任務指令

「請依附上的 VAC 與素材完成任務。先核對目標、素材及可用工具，再選擇工作方法；重要缺口請指出。依現有授權執行可完成的步驟，交付實際檔案與驗收結果。不可把未執行操作寫成已完成。」

## 交付檢查

- 實際檔案存在且能開啟。
- 內容、格式與限制符合 VAC。
- 說明尚未完成、需補錄或需人工處理的部分。
- 發布操作依任務授權，不以完成製作推定授權對外發布。

## 教學練習

學員選一項工作，填寫一份 VAC，辨識三層各自負責什麼，再交付最小成果。評量四項：目標明確、分工正確、成品符合規格、限制說明誠實。每項 0–2 分，共 8 分；此為練習設計，非研究驗證量表。
